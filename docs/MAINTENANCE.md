# 维护公开版本

公开版为一次源码快照，拥有独立 Git 仓库，不携带旧提交历史。

后续可以先在公开版开发通用功能，再将相应提交应用到私人版。个人差异优先保存在 .env、数据库、上传内容或其他被忽略的配置中。

首轮审查的通用修复及其回归测试已经完成，见 [修复记录](AUDIT_FIXES.md)。使用不同语音服务的实例仍需保留各自适配代码；语音和素材配置完全统一之前，更新时要单独核对这些差异。

如需从私人版更新：逐个移入必要源码，检查 diff，执行 npm run check、npm test 和 npm run release:check。不要整目录覆盖，不要复制 .git、数据库或私人部署脚本。保留公开版的通用素材、TTS 配置方式和忽略规则。

每次同步记录来源提交或快照、文件清单、同步前后哈希、实例差异与测试结果。覆盖前备份将改动的代码；涉及数据库时先制作能覆盖 WAL 的一致性备份，并检查完整性。代码同步和正式部署分别记录，不把更新本地目录视为线上已生效。

发布前审阅暂存内容，并确认 LICENSE 与素材来源适合你的授权意愿。
