# 配置与运行

## 1. 准备环境

- 安装 Node.js 与 npm。`package.json` 声明 Node.js **≥ 22.5.0**；推荐使用 Node.js 24（本次验证版本为 24.18.0），确保 `node:sqlite` 可直接使用。早期 22.x 版本可能需要 SQLite 实验开关。
- 准备一个可访问的 LLM 服务，以及自己的 API Key 和模型名称。
- 获取源码后，进入仓库根目录（包含 `package.json` 的目录）。

```bash
npm ci
```

前端由 Express 直接提供，无需单独构建，也无需安装独立数据库服务。

## 2. 配置本地环境

复制应用目录中的 `.env.example` 为 `.env`。

PowerShell：

```powershell
Copy-Item .env.example .env
```

macOS / Linux：

```bash
cp .env.example .env
```

默认配置即可在本机启动：

```dotenv
PORT=3000
HOST=127.0.0.1
CYBERSEA_AUTH_USER=
CYBERSEA_AUTH_PASSWORD=
CYBERSEA_DATA_DIR=
```

| 配置项 | 说明 |
| --- | --- |
| `PORT` / `HOST` | 默认监听本机 `127.0.0.1:3000` |
| `CYBERSEA_AUTH_USER` / `CYBERSEA_AUTH_PASSWORD` | 两项同时填写后启用浏览器 Basic Authentication；只填写一项会阻止启动 |
| `CYBERSEA_DATA_DIR` | 可选数据目录，建议使用绝对路径；留空使用应用目录下的 `data/` |

不要将 `.env`、数据库、备份或上传内容提交到公开仓库。若需要对外提供实例，应启用访问保护并使用 HTTPS；默认配置面向本地使用。

## 3. 启动与首次设置

```bash
npm start
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。启动时会创建数据库并执行版本迁移。

在「设置」中填写聊天 API 基础地址、API Key 与模型名称。基础地址应填写到服务的 API 根路径，例如服务要求 `/v1` 时包含该路径，**不要再附加 `/chat/completions`**，代码会自动追加。

聊天优先使用 `tools` / `tool_calls`，并将工具结果回传为 `role: tool`。若服务明确返回不支持 `tools` 参数的 HTTP 400 错误，会改用旧式 `functions` / `function_call`，并在当前进程内记住该服务与模型的协议选择；鉴权失败等无关错误不会触发协议重试。一次回复包含多个工具调用时逐项执行，一轮聊天最多执行 8 次。填写角色设定与补充设定后，即可开始对话。

模型密钥等设置保存在本地 SQLite 中，并会回显到设置页；请将整个数据目录视为私人数据。聊天上下文及相关工具结果会发送给所配置的模型服务。

档案页的两块立绘区域可点击选择 PNG、JPEG、GIF 或 WebP 图片（最大 10MB），上传成功后自动保存，刷新后仍可显示。再次点击可更换，立绘与聊天头像分开管理。图片存放于实例自己的 `uploads/`，路径保存在数据库；默认不附带个人立绘，也不会随源码提交。首次运行新版本时会自动添加立绘字段，已有数据库按迁移流程先备份。

## 4. 按需开启外部能力

基础文字聊天不依赖下列可选服务。

| 能力 | 配置与依赖 |
| --- | --- |
| 图片识别 | 设置页配置视觉 API 地址、密钥与模型；需要支持图片输入的 Chat Completions 服务 |
| AI 生图 | 设置页配置生图模型及 API；调用 `/images/generations` 并读取 `b64_json`。参考图参数 `reference_images` / `reference_strength` 属于服务扩展，需服务端支持 |
| 语音消息 TTS / 故事朗读 | 设置页填写完整 TTS 地址与可选密钥；当前请求为 JSON `{ "text": "..." }`，期望返回音频二进制，请使用符合该约定的服务 |
| 语音识别 STT | 自行运行兼容的 SenseVoice HTTP 服务，在 `.env` 添加 `SENSEVOICE_URL`；默认本机地址为 `http://localhost:50000/api/v1/asr`。后端发送 `files` 与 `lang`，读取 `result[0]` 文本及情绪标签 |
| 模拟语音通话 | 需要麦克风权限、STT 和 TTS；与普通朗读共用设置页的 TTS 配置，通过服务端合成，不包含参考音频；如使用 GPT-SoVITS，需自行提供接收 `{text}` 并补全参考音频参数的适配服务 |
| MCP 工具 | 设置页填写兼容远程 SSE 服务的地址、可选请求头并启用；服务需符合当前客户端的发现和调用流程 |
| 主动消息 | 在设置页配置触发时间、频率与免打扰规则；后端需持续运行，并使用运行环境的本地时区 |
| Web Push | 配置 `VAPID_PUBLIC_KEY`、`VAPID_PRIVATE_KEY`、`VAPID_EMAIL`，其中后者作为 VAPID subject（如 `mailto:` 联系地址）；需浏览器授权及安全上下文（HTTPS 或 localhost） |
| 天气提醒 | 配置城市并启用相关功能；后端访问外部天气服务 `wttr.in` |

语音识别与通知环境变量见 `.env.example`。外部服务的费用、可用性及数据处理方式由所选服务决定。

## 5. 检查与备份

应用目录提供以下命令：

```bash
npm run check
npm test
npm run backup
```

分别用于 JavaScript 语法检查、自动测试及已存在数据库的备份。测试使用临时数据库或模拟服务，覆盖迁移、备份、访问控制、工具调用，以及记忆条目版本、来源失效、独立任务进度、检索和上下文预算；不代表所有界面和外部 AI 服务均已完成验证。

默认数据库位于 `data/app.db`，备份位于数据目录下的 `backups/`。上传文件位于 `uploads/`，不随 `CYBERSEA_DATA_DIR` 改变；数据库备份不包含这些文件，完整迁移实例时需另行保存。

## 当前界面范围

- 日历提醒目前只保存开关，界面标注“即将上线”；尚未实现日程通知。
- 书籍暂不保存阅读进度。批注可以在界面创建/显示，单条删除目前只有接口。
- 故事支持新建时编辑与自动保存，重开后没有编辑入口；计划正文没有修改入口，完成后的结果、评语和感想可以修改。
- 相册配文可以显示，修改配文目前只有接口；用户界面没有配文编辑按钮。
- 当前提供深海主题，没有主题切换、环境音播放和音量调节控件。背景音乐可自行添加，通过唱片播放/暂停；默认不附带 BGM，默认音量为 0.35。
- 真实 STT/TTS、完整真实长通话、视觉/生图、MCP、推送与天气的可用性取决于外部服务配置。已有部分模拟验证不代表所有真实服务均完成联调。

## 调度与演示实例

后台进程持续运行时，已启用的主动消息和记忆维护等任务才会执行。主动消息及多数业务调度使用服务器本地时区；记忆维护另外提供时区设置。

如需仅查看界面，可在 `.env` 设置 `CYBERSEA_DISABLE_SCHEDULERS=1` 后启动，避免后台定时任务执行。手动聊天及其触发的写入仍然有效。

默认图标与合成环境音可用 `npm run assets:generate` 重建。作者提供的 AI 生成深海背景保持原样；背景音乐由使用者自行添加为 `public/audio/bgm.mp3`，来源说明见 [素材清单](ASSETS.md)。
